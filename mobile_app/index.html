Technical Reference

Comprehensive hardware pinout mapping and software runtime features for Mr.&Ms Luna companions.

🔌 Hardware Connections

  • Microcontroller: ESP32-C3 SuperMini RISC-V SoC (BLE v5.0 / WiFi Coexistence).
  • OLED Screen: SSD1306 I2C (128x64 pixels). SDA ➔ GPIO 20, SCL ➔ GPIO 21.
  • Capacitive Touch: GPIO 1 contact plate. Supports single, double, & triple taps.
  • Audio Buzzer: Passive piezo buzzer on GPIO 2. Square-wave frequency synthesizer.
  • Power & Flash: USB-C port (115200 Baud serial interface) for settings, power, and logs.

⚙️ Software Features

  • Auto-Reconnection: BLE scan checks connection state every second and auto-reconnects instantly.
  • Sleep Bypass: Sleep transitions and timeouts are disabled to maintain persistent connectivity.
  • WiFi Coexistence: Runs with WIFI_PS_NONE to eliminate radio channel latency.
  • Drift-Free RTC: Local milliseconds-tracking system clock with auto-sync from client.
  • In-Device Settings: Triple tap touch sensor opens an interactive OLED menu configuration.
  • Melody Library: Plays 8-bit sound effects (Jump, PowerUp, Coin, GameOver, Chirp, Startup).
  • NVS Persistence: Preferences saved to non-volatile flash memory and persist across power cycles.
